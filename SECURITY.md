# Security Policy

SentinelOSINT is a defensive portfolio project.

## Reporting a vulnerability

If you discover a security issue in the code, please report it privately to the repository owner rather than opening a public exploit demonstration.

## Scope principles

The project intentionally excludes:
- credential theft or session bypass
- private-account collection
- doxxing or stalking workflows
- covert individual monitoring
- facial recognition or biometric identification
- deceptive personas or social engineering
- collection intended to facilitate harm

Synthetic scenarios and fictional assets are used where appropriate so the analyst workflow can be demonstrated without implying real operational intelligence.
